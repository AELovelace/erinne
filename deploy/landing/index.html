A file server that remembers

📁 Files

A full file manager in the browser for your own File box and every shared library. It sits on the same folders as your Windows file share.

🕰 Versions

Every change made through Erynne, Claude or the editor keeps the old copy. Restore any version in a click.

🗑 Recycle bin

Deleting never destroys anything at once. Each location has its own bin.

👁 Previews

PDFs, Markdown, documents, code and images open right in the page, with comments beside them.

💾 Desktop backup

A small Windows and Linux app keeps chosen folders backed up to your File box, from the office or anywhere.

🔐 Real permissions

Sign in with your domain account. The folder rights you already have decide what you, and Erynne, can open.

Work together

📖 Wiki

Your organisation's own pages, edited in the browser with a live preview, task boxes you can tick, and conflict-safe saves. Erynne searches and cites them too.

💬 Rooms

Team channels and direct messages, live as they're written, with mentions and an inbox.

✉ Messages

Notes between colleagues, announcements for everyone, and word from Erynne when something you asked for is done.

🗨 Comments

Questions and notes that live on the file itself, not lost in a chat.

Bring your own Claude

  • A remote MCP server. Connect Claude on the web, phone, Desktop or Claude Code with a normal sign-in.
  • Acts as you. Claude searches, reads and (if you allow it) edits files with exactly your access, and only what's shared with Claude.
  • Proposals, not surprises. Changes Erynne or Claude draft wait for your approval before anything happens.
  • Every look is logged. Admins see each search and which files' text went back to Claude, and can cut a connection at once.

$ claude mcp add --transport http mnemerynne https://your-server/mcp
