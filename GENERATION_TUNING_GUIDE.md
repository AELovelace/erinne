# Casino rules and tuning

`mnemerynne/casino.py` is the authority. Randomness comes from `secrets.SystemRandom`; browser animation is decorative. These games do not use generated narrative content or a model.

| Setting | Current behavior |
| --- | --- |
| Seats / rooms | 8 seats per room; 100 live rooms; create blocked at 3 joined rooms per identity per game |
| Coins (online tables) | One purse per account, 1,000 to start (`coins.py`); free refill to 1,000 below the minimum spin/round cost (30 for three-line slots, 10 otherwise) between rounds |
| Credits (local tables) | 1,000 per seat, per table, gone when the table ends; same refill rule |
| Coin rewards | Prism Drop: 1 per 10 points, 200 a day (`PRISM_POINTS_PER_COIN`, `PRISM_DAILY_CAP`). Lumi Pet: 25 for the day's first visit (`PET_VISIT`); fight wins pay `floor((15 + 3 × enemy level + tier bonus) × 0.6)` with no daily limit. Lumi's prices are in `lumipet_data/*.json` |
| Bets | 10–500, multiples of 10; slots use a per-line bet and reserve 3× that amount; replaced bets refund the full prior reservation |
| Timers | 45s betting; 30s blackjack; 6s wheel/race/reels; 10s results |
| Expiry | 2h without a table request; stale rows removed on room creation or a balance check, handing back bets still open |
| Blackjack | One 52-card deck each round; dealer stands on soft 17; naturals 3:2; normal wins 1:1; ties push |
| Roulette | Uniform 0–36; straight return 36×; outside return 2×; zero loses outside bets |
| Horses | Six equal chances; winner returns 5× stake |
| Slots | 3 columns × 3 rows, six equally likely symbols per cell; top/middle/bottom pay separately; per line: stars triple 24×, other triples 12×, pair 1× the line bet |

Returns include the stake, which was deducted when the bet was placed. Update the client rules text, Media help and payout tests with every rule change. Coins stay on this server, with no external wallet or money integration. Server deadlines advance on the next table request; a reconnect resumes the persisted phase and advances an elapsed deadline.

Three-line slots store `slot_lines: 3` on the round, a row-major 3×3 `reels` array per player, and three `line_payouts`. Total return is their sum; net is total return minus `bet × slot_lines`. For example, 50 per line costs 150, and a single ordinary triple returns 600 (net +450 if the other lines lose). Columns and diagonals never pay. A saved round without `slot_lines` keeps its old single-line wager and flat reels through settlement; the next round adopts three lines. No database migration is needed.

Roulette's SVG uses the European single-zero pocket order in `static/games/casino/roulette.js`. Its six-second spin follows the server deadline; after receiving the result, a 1.4-second decorative landing places the ball at that number, including the rotor's rotation. This occurs within the existing results window and never delays or determines settlement. Reopening a settled round and reduced-motion mode show the final position immediately. Pick highlights cover the pending choice, while the winning pocket gets a gold highlight.

## Lumi Pet

This companion uses authored copy and native SVG/CSS, with no model or image-generation dependency. Tune her needs in `mnemerynne/lumipet.py`. Each meter follows `100 - B·ln(1 + t/tau)`, with tau chosen so the last 25% always takes `LAST_QUARTER_HOURS` (24). `DECAY` holds B per meter: hunger 30 (full to 25% in about 17 hours, empty in about 41), energy and joy 40 (about 23 and 47 hours). A smaller B empties faster at the top. New pets start at 85. A cuddle gives 5 joy; cuddles and snacks each have a 30-second cooldown (`COOLDOWN`). A nap is a 5-minute timed rest worth 35 energy on finishing (`NAP_MINUTES`, `NAP_ENERGY`); play lasts as long as the toy says. Rewards land at the moment a nap or play finishes, then decay normally. Automatic sleep is 22:00–07:00 in device-local time (`rules.js`), and a gentle wake lasts fifteen minutes (`AWAKE_MS`).

Snacks, treats and toys are `mnemerynne/lumipet_data/items.json`: `fullness` and `joy` for food, a `boost` (power, guard or luck, held for the battles to come) on treats, and `minutes`, `joy`, `energy` and `hunger` on toys. Each kind of snack and toy needs one free item, so nobody is left unable to feed or play; the pantry holds 99 of each. The catalog is checked at start and a mistake stops the server with a message naming the item. Prices are first guesses and can be changed freely. The old version-1 localStorage key `mnemerynne-game:lumi-pet:companion` is only read once per account, to bring its happy moments and glow across. Presentation updates once a second while visible and asks the server every 15 seconds; reduced motion disables CSS animation.

**Battles** tune in `mnemerynne/lumibattle.py` and `lumipet_data/battle.json`. Damage is `floor((((2·level/5 + 2) · power · attack/defense) / 50 + 2) · PACE)`, then a 0.85–1.0 roll and the element (weak ×1.5, resisted ×0.75, immune ×0, her own glow's spells ×1.1). `PACE` (1.7) sets how long fights last. Enemies appear at her level ±2; `TIERS` multiplies their health, attack and defense (common 0.60/0.80/0.85 up to legendary 1.40/1.15/1.15) and adds bonus EXP; `ENEMY_HP_GROWTH` (1.0) doubles enemy health by level 50 to keep pace with her skills. Each enemy's `shape` leans it (a Puddle Slime shrugs off claws, a Void Jelly spells) and its moves unlock by `level`. Skill nodes cost `NODE_COSTS` (1,1,2,2,3,3,5,5). Measured with real builds and a simple always-attack player (600 fights each, no potions): level 1, common 92% wins in about 4 turns, rare 48%; level 25 with one and a half trees and three mods, rare 90%, epic 36%; level 50 with two trees and five mods, epic 76%, legendary 2% without the right element. Potions, healing and Defend raise those. To measure a change, build a fight with `lumibattle._lumi` and `_enemy` and loop `resolve` a few hundred times with a seeded `random.Random`. Prices: potion 20, wake-up 50, respec 100, mods 400, Star Capsule 150 with odds 55/25/14/5/1; house objects 90–350 and accessories 60–180 are first guesses.

**The dungeon** tunes in `mnemerynne/lumidungeon.py`. `ROOMS` (11–13) and the grid set a floor's size; each floor has 3–4 enemies, 2 treasure rooms, 1 game, 1 vault and the stairs. `TIERS_BY_DEPTH` sets how tough enemies are per floor (floor 1 is 70% common, 30% uncommon; floor 5 and deeper is 20% rare, 55% epic, 25% legendary) and `ENV_BIAS` (70) how often they come from the environment's own elements. Enemy level is Lumi's, ±1, plus one per floor below the first. `_coins` pays 10–25 a treasure room, times 1.5 per extra floor; a vault pays three times that, a potion, a trophy she lacks, and a dungeon-only mod `MOD_CHANCE` (8% + 4% a floor) of the time. Games pay 2.5× for the right cup and 0.3× for a wrong one; cards pay by pairs found within `FLIPS` (14) turns. Rune doors allow `RUNE_TRIES` (8) guesses of `RUNE_SLOTS` (4) runes. Sokoban doors draw from the first `4 + 3 × floor` levels of `sokoban.json`, which is sorted easiest first; remake it with `python/make_lumi_sokoban.py --count 16 --seed 7`. **Dialogue** tunes in `mnemerynne/lumitales.py`: `VOICE` is the system prompt for both the generator and live mode, `SCENARIOS` describes each moment, `MAX_LINE` (200) caps a line. The generator uses `claude-opus-5-5` at medium effort unless `--model` says otherwise; live mode uses the person's own model at low effort. No sampling parameters are set: current Claude models reject them.

**Health between trips** tunes in `mnemerynne/lumibattle.py`: `MEND_MS` (ten minutes for a whole bar by waiting; it equals `FAINT_MS` so a beaten Lumi is whole exactly when she wakes), `NAP_MEND` (2: a nap mends twice as fast, so the five-minute nap covers a whole bar) and `POTION_MEND` (0.5). Bought food mends its `fullness` as a percentage, from `lumipet_data/items.json`; free food mends nothing, or the apple would make waiting pointless.

## Shared-TV casino controls

Each remote gets 1,000 free credits, independent `amount` (initially 50), `pick` (first option) and `hand` (Hit) fields. Arrow edits do not place a bet; Enter joins first, then submits bets, confirms Hit/Stand or refills when below the game's minimum. Play belongs to the first seated player. The existing 8-seat cap includes remote and ordinary account guests, with no extra TV seat. A late join watches the active round. Shared slot cards show all three lines per player, including the full three-line stake.

Pair every controller to the TV owner's account using existing screen/remote pairing. Signed inputs expire after 90 seconds; persisted deduplication receipts last 120 seconds and are bounded to 1,024 per room. Hitting the receipt limit refuses inputs until old receipts expire, rather than allowing replay. The client queue holds at most 128 pending inputs. Round/phase changes require the player to press again. Remote re-pairing or removal invalidates its old proof/identity; remove the old seat from the TV if needed. Empty TV tables remain resumable until ended or idle expiry. End TV table deletes the entire room; Remove player forfeits that seat's balance and stake and transfers host to the first remaining player.

## Display scale

Games on paired TVs use the existing UI scale: Automatic is 1× below 2400 CSS pixels wide, 1.5× from 2400, and 2× from 3000. Saved Text size settings (0.75×–3×) override Automatic, including inside game frames. The parent's actual scale is forwarded so frame size and safe-area margins do not choose a different size. Ordinary unpaired desktop browsers retain their sizing; browser/OS scaling already affects CSS viewport size and must not be multiplied again. Root rem dimensions scale the layout, while canvas/SVG coordinates continue to express the same game geometry. No timers, payouts, random generation or pet behavior change with display scale.
