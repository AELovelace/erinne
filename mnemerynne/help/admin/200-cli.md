# Command-line reference

On the server every command runs as `sudo mnemerynne-admin <command>` (the service user, with the settings file); in development as `uv run mnemerynne <command>`. Passwords are always prompted, never passed on the command line.

## Running

| Command | Does |
|---|---|
| `serve` | The web app (`mnemerynne-web`). |
| `worker [--once]` | The ingestion worker (`mnemerynne-worker`); `--once` exits when no jobs are due. |
| `init-db` | Create or migrate the database (the services do this at start too). |

## Accounts

| Command | Does |
|---|---|
| `list-users` | Every user with role, state and domain account. |
| `create-user NAME [--role admin]` | A user with their File box; prompts for the password. |
| `reset-password NAME` | Sets a new password; signs them out everywhere. |
| `set-role NAME user\|admin` | Local admin or regular user. |
| `delete-user NAME [--yes]` | Removes the user with their File box and memories. |
| `forget-memories NAME` | Wipes what Erynne remembers about them. |
| `revoke-tokens NAME` | Ends all their Claude tokens and connections. |

## Libraries and files

| Command | Does |
|---|---|
| `create-library NAME` | A shared library. |
| `grant LIBRARY USER [--write]` | Give a user access (write access with `--write`). |
| `import FOLDER --library NAME \| --user NAME [--flat]` | Bulk upload keeping subfolders (`--flat` puts everything at the top). |
| `purge-trash [--days N]` | Empty recycle-bin items older than N days now (the worker does it hourly). |
| `share-init` | Prepare the SMB share: marker, `Users\`, trash; moves empty File boxes onto it. |
| `share-scan` | Sync with the share now (the worker does it every minute). |
| `share-export --user NAME \| --library NAME \| --all [--dry-run]` | Move File boxes and libraries stored inside Mnemerynne onto the share. |

## Indexing

| Command | Does |
|---|---|
| `reindex [--file ID] [--reextract]` | Re-chunk and re-embed (optionally re-read). |
| `reembed` | Rebuild all vectors after changing the embedding model. |
| `reclassify` | Make stored-only files searchable that this version can read. |

## Backups and updates

| Command | Does |
|---|---|
| `backup [--dest DIR] [--keep N]` | Database snapshot plus new blobs and versions (the timer does it nightly). |
| `restore [--from DIR] [--date YYYY-MM-DD] [--list] [--force]` | Put a backup back; services must be stopped. |
| `mnemerynne-admin check-updates` | What's new on GitHub and what an update would change. |
| `mnemerynne-admin update [--yes]` | Back up, update, restart, check; undo on failure. |

## Migration

| Command | Does |
|---|---|
| `migrate-microjames --source DIR [--import-files] [--dry-run]` | Import users, libraries, grants and files from a MicroJames install. |
| `deploy/linux/migrate-from-erinne.sh` | Move a pre-rename "Erinne" install to Mnemerynne (run once, as root). |

## Evaluation and training

| Command | Does |
|---|---|
| `draft-gold`, `eval-retrieval`, `eval-answers [--agent]`, `eval-gate` | Gold sets and measurements ([Indexing](indexing.md#evaluation)). |
| `router-data`, `train-router` | Draft labelled messages and train the message router. |
| `gen-sft` | Fine-tuning data from the teacher model. |

`mnemerynne <command> --help` prints every option.
