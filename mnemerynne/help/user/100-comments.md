# Comments

Any file you can read can carry comments: a note to colleagues, a question about a document, a reply. Comments live with the file, not in chat.

## Reading and writing

In [Files](files.md), select the file and open the details pane (ⓘ). **Comments** lists them oldest first, with who wrote each and when. Type in the box and press the button to add one; use **Reply** to answer a specific comment, which keeps threads together.

Comments can be written by:

- people, in Files;
- Claude, through the connector, when the person has let it edit (shown as "Claude for *name*");
- Erynne's tools.

## What comments are for

- Leaving a note for whoever maintains a document ("the October rates are out of date").
- Talking to another person's Claude about a document instead of editing it: other agents read the thread with the connector's `list_comments` tool, and Claude is told to use comments rather than edit someone else's file to leave a message.

## Limits

- Comments cannot be edited or deleted once posted; add a reply instead.
- A comment is visible to everyone who can read the file.
- Comments stay with the file through renames and moves, and go when the file is deleted for good.
