# Scopes and citations

## Where answers come from

Erynne answers only from places you can read:

- **Your File box**: your own files. Nobody else sees them.
- **Libraries**: shared collections an admin publishes (brand standards, system manuals, department folders). Which ones you see depends on grants to you or your groups, or, for libraries on the organisation's file share, on the Windows permissions of your domain account.
- **SharePoint libraries**, if your organisation linked them, and only the files your own Microsoft account may open there.
- **Internal systems** (ticketing, monitoring, hotel stats), when an admin has set them up and you are in their group. Live questions ("what's the status of ticket 4812?") are answered from the system itself.

Everything else is invisible to her. Admins see who can reach what on Access → Who can see what; your Preferences page lists your groups.

## Choosing a scope

Use the 🔎 chip on the Ask tab to search one library or one folder. A scope narrows the search; it never widens it. It is useful when a term appears in many documents ("rates" in both the OPERA manual and the brand standards) or when you know where the answer lives.

## Reading a citation

Each citation names the file and the place in it:

| Document | What the citation names | Where it opens |
|---|---|---|
| PDF | the page | the page in the viewer |
| Markdown or text | the heading | the heading in the rendered page |
| Word | the heading | that section of the extracted text |
| PowerPoint | the slide | that slide's text |
| Excel, CSV | the sheet and rows | those rows |
| Code and config | the lines | those lines |
| Internal system | the operation and the time of the call | the stored response the answer was based on |
| SharePoint | the page, with *Open in SharePoint* | the page in Erynne's viewer |

When something matters (a rate, a procedure, a deadline), click through. The citation is the source of truth; the answer is Erynne's reading of it.

## Why "not found" happens

- The document isn't shared with you, or isn't in the chosen scope.
- The file is still being read (status Queued or Indexing in Files), or couldn't be read (Failed or Stored).
- The document says it differently. Try the system's own term.
- The answer really isn't written down anywhere you can see. That is worth telling whoever maintains the documents, or putting on the [wiki](wiki.md).

## Passages, not whole files

Erynne searches **passages**: a page, a heading section, a slide. An answer may draw on several passages from several files, and it cites each one. Very long files are fine; a 3,000-page manual is searched page by page.
